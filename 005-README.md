## Erweiterungsprinzip

Neue inhaltliche Kapitel werden vor dem Forschungs- und Referenzarchiv eingefügt. Das Archiv, die Lizenz und die nummerierte README rücken nach hinten; interne Links werden entsprechend aktualisiert. Studienkennungen `S-001` usw. und Grundlagenkennungen `R-001` usw. bleiben dauerhaft stabil.

## Wissenschaftliche Einordnung

Forschungspositionen, Hypothesen, theoretische Grundlagen, experimentelle Befunde und klinische Evidenz werden unterscheidbar dokumentiert. Diese Dokumentation enthält keine eigenständige Therapieanleitung.
